# Valentines website

Small single-page Valentines site. Open `valentines.html` in a browser to view.

Features:
- Responsive card with animated heart
- "Show Surprise" launches floating hearts
- "Reveal Message" toggles a short message

Next steps:
- Replace inline copy with your personal message
- Add images or background music if desired

Add your photo:
- Replace `images/photo.svg` with your own image file (for example `images/photo.jpg` or `images/photo.png`).
- Example: copy your photo to `images/photo.jpg` and it will appear on the page when the filename matches.
